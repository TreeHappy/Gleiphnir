## Goal / Non-Goals

- **Goal:** Plan-only spec for a single static binary `gleiphnir` (like Docker `sbx`) that replaces host `bash`+`mise` runtime, with only hosting tech `qemu-system-x86_64`/`qemu-img` or `firecracker` + `podman` (inside VM). Host lean: no `pwsh` (done `001`/`002`), no `python` required at runtime (keep for now per `002` but binary will embed ISO), no `mise` needed for end-user (keep `mise` during dev per confirm, but `gleiphnir up` works without). Two profiles: long-running dev (persistent volumes `vm/guest/bin/sandbox-shell:11` `gleiphnir-home-*`+`sandbox-mise`+`/srv/sandbox/<user>` on `DATA_DISK` `config/sandbox.env:20`) and AI agent microVMs (ephemeral Firecracker, `virtiofs`/`vsock`, snapshot).
- **Non-Goals:** No code yet (planning), no Windows (`001`), no host `pwsh` (`002`), no proxy/secrets impl (`003`/`004` decisions feed this).

## Proposal: Go static binary spec

**Lang/build:** Go 1.23+, `CGO_ENABLED=0 go build -ldflags="-s -w"` → `dist/gleiphnir` 12-18MB static, `go:embed` assets, `goreleaser` deb/rpm, SBOM via `syft` `mise.toml:9` or `gleiphnir sbom` `vm/scripts/sbom.sh`.

**CLI (cobra+carapace, replaces `vm/files/carapace/specs/gleiphnir.yaml:79`):**

```
gleiphnir up [--launcher qemu|firecracker]   # was mise run up mise.toml:287
gleiphnir down
gleiphnir vm prepare|start|stop|kill|console|ssh|wait|info|clean  # vm/scripts/*.sh
gleiphnir network up|down|status # vm/scripts/network-*.sh
gleiphnir user add|remove|list     # vm/scripts/manage-user.sh
gleiphnir policy init|ls|allow|deny|rm|check|preset # manage-policy.sh → guest sandbox-policy:1
gleiphnir container build|info
gleiphnir secrets sync|list|status # secrets.sh → podman secret (004)
gleiphnir image download|info
gleiphnir --version --help
```

Carapace completions generated by binary directly, replaces `vm/files/gleiphnir` shim.

**Config:** Reads `config/sandbox.env` (`koanf`/`viper`) + env overrides, defaults mirror `vm/scripts/lib.sh:29` (`VM_NAME=gleiphnir` `config/sandbox.env:6`, `VM_CPUS=4` `config/sandbox.env:18`, `DATA_DISK_SIZE=20G` `config/sandbox.env:20`, `HOST_SSH_FORWARD_PORT=2233` `config/sandbox.env:50`, etc.). `QEMU_EXTRA_ARGS` `config/sandbox.env:22` pass-through.

**Embedded assets (`go:embed`):**

- `vm/cloud-init/user-data.yaml.tpl`, `network-config.bridge.yaml`, `meta-data`
- `vm/guest/bin/*` (`sandbox-shell:1`, `sandbox-policy:1`, `sandbox-proxy` or tinyproxy shim `003`), `vm/guest/policy-presets/balanced.txt`, `vm/guest/lib/build-container.sh`
- `container/*` (`Containerfile:1`, `mise.toml`, `dotfiles/*`, `carapace/specs/fenrir.yaml` — gleiphnir spec generated, not embedded)

Rendering replaces `template_userdata.py:17-45` with `text/template` `__TOKEN__`→`string` (keep `python` shim until native `go-iso9660` ISO replaces `build_seed_iso.py` `pycdlib`).

**Host abstraction:**

```go
type Launcher interface { Prepare(ctx) error; Start(ctx) error; Stop(ctx) error; Info() VMInfo }
type QEMU struct { ... }       // qemu-img create -F qcow2 -b $BASE_IMAGE vm/scripts/prepare-vm.sh:37, qemu -daemonize vm/scripts/start-vm.sh:141, unix monitor, TAP+netlink+iptables vm/scripts/network-up.sh:26
type Firecracker struct { ... } // api via http+vsock, kernel + initrd, virtiofs for /srv/sandbox if persistent else tmpfs, vsock for policy/secrets
```

Dev default `QEMU` (persistent `SYSTEM_DISK`/`DATA_DISK` `config/sandbox.env:62-66`, `ip`/`iptables` `bridge 192.168.100.0/24` `config/sandbox.env:39-44`), AI default `Firecracker` (128-512MB, snapshot, boot <3s, ephemeral). Selection via `--launcher` or `GLEIPHNIR_LAUNCHER` env.
