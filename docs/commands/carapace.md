# Carapace — shell completion + executable specs

[Carapace](https://carapace.sh) provides multi-shell tab completion for Gleiphnir via YAML specs.

## Specs

| CLI | Spec file | Deployed to | Alias | Executable |
|---|---|---|---|---|
| `fenrir` | `container/files/carapace/specs/fenrir.yaml` | `/etc/carapace/specs/fenrir.yaml` → `~/.config/carapace/specs/` via `container/files/mise.toml:77` `dotfiles` task | `fen` | No (completion only, delegates to `gdu`/`yazi`/`sandbox-*`) |
| `gleiphnir` | `vm/files/carapace/specs/gleiphnir.yaml` **(host only)** | host `~/.config/carapace/specs/` (manual `ln -s`) + shim `~/.config/carapace/bin/gleiphnir` via `carapace --run` + VM `/usr/local/bin/gleiphnir` | `gle` | **Yes** — `run: "[mise, run, ...]"` or `run: | #!/bin/sh` for flag-bearing commands |
| `mise` | `container/files/carapace/specs/mise.yaml` | enhanced task completion | — | No |

> **Gleiphnir spec is executable** — every leaf has `run:`. `carapace --run` / shim executes `mise run <task>` → `vm/scripts/*.ps1` → `ssh admin@VM "sudo sandbox-*"` → `ufw`/`proxy`. `fenrir.yaml` remains completion-only. Legacy bash shim `vm/files/gleiphnir:50` (`run_mise`) remains for fallback; `container/files/gleiphnir` removed (host-only). Host `mise.toml:11` lists `carapace = "latest"`.

## Setup

### In-container (automatic)

```bash
# Already wired via dotfiles task + bashrc/profile.ps1
echo $CARAPACE_SPEC_DIR  # /etc/carapace/specs
carapace --list | grep -E "fenrir|gleiphnir|mise"
fen --help
gle --help  # alias inside container (if VM shim present)
```

Via `container/files/dotfiles/bashrc:23` and `profile.ps1:30` (`CARAPACE_SPEC_DIR=/etc/carapace/specs` + `carapace _carapace`).

### On host (manual one-time) — gleiphnir is host-only

```bash
# Install carapace (via mise)
mise use carapace@latest

# Link specs — fenrir is container, gleiphnir is host (vm/scripts)
mkdir -p ~/.config/carapace/specs
ln -sfn "$PWD/container/files/carapace/specs/fenrir.yaml" ~/.config/carapace/specs/fenrir.yaml
ln -sfn "$PWD/vm/files/carapace/specs/gleiphnir.yaml" ~/.config/carapace/specs/gleiphnir.yaml
ln -sfn "$PWD/container/files/carapace/specs/mise.yaml" ~/.config/carapace/specs/mise.yaml

# Shell init (bash)
echo 'source <(carapace _carapace)' >> ~/.bashrc
# Shell init (pwsh) — add to $PROFILE:
#   carapace _carapace | Out-String | Invoke-Expression

# Add gleiphnir to PATH via carapace shim (preferred) — shim is generated by `carapace _carapace`
export PATH="$HOME/.config/carapace/bin:$PATH"
# Legacy fallback: sudo ln -sfn "$PWD/vm/files/gleiphnir" /usr/local/bin/gleiphnir
gleiphnir --help   # via shim: carapace --run vm/files/carapace/specs/gleiphnir.yaml
```

### Host `mise` vs `gleiphnir`

`gleiphnir` is a thin alias over `mise run`. Both work:

```bash
mise run vm:start
gleiphnir vm start     # nested subcommands, carapace-completeable, executable via shim
gle vm start           # short alias
```
