# Gleiphnir Command Reference — `fenrir` (`fen`) + `gleiphnir` (`gle`)

> Two nested CLIs, one completion system ([Carapace](https://carapace.sh)).
> - **Fenrir** (`fen`) — **in-container** sandbox CLI. Uses `gdu` for disk inspection
>   and `yazi`/`yasi` for browsing, both installed via `container/files/mise.toml:6`.
>   No hand-rolled `du`/`ls` — delegation to `gdu`/`yazi` is required.
> - **Gleiphnir** (`gle`) — **host/VM** orchestration CLI. Every leaf **calls `mise run <task>`**
>   (`mise.toml:1`), via nested `subcommands` (e.g. `gleiphnir vm start` → `mise run vm:start`).

Specs live at (gleiphnir is **host-only**, `vm/scripts/`):

| CLI | Spec file | Deployed to | Alias |
|---|---|---|---|
| `fenrir` | `container/files/carapace/specs/fenrir.yaml` | `/etc/carapace/specs/fenrir.yaml` → `~/.config/carapace/specs/` via `container/files/mise.toml:77` `dotfiles` task | `fen` |
| `gleiphnir` | `vm/files/carapace/specs/gleiphnir.yaml` **(host only)** | host `~/.config/carapace/specs/` (manual `ln -s`) + shim `~/.config/carapace/bin/gleiphnir` via `carapace --run` + VM `/usr/local/bin/gleiphnir` (cloud-init) | `gle` |
| `mise` | `container/files/carapace/specs/mise.yaml` | enhanced task completion | — |

> **Specs are executable** — `vm/files/carapace/specs/gleiphnir.yaml` contains `run:` for every leaf (`run: "[mise, run, ...]"` or `run: | #!/bin/sh` for flag-bearing commands). `carapace --run` / shim `~/.config/carapace/bin/gleiphnir` (generated by `carapace _carapace`) executes `mise run <task>` → `vm/scripts/*.ps1` → `ssh admin@VM "sudo sandbox-*"` → `ufw`/`proxy`. Legacy bash shim `vm/files/gleiphnir:50` (`run_mise`) remains for fallback but is no longer required; `container/files/gleiphnir` has been removed (host-only). Container shells load via `container/files/dotfiles/bashrc:23` and `profile.ps1:30` (`CARAPACE_SPEC_DIR=/etc/carapace/specs` + `carapace _carapace`); host needs manual link + shim `PATH` (see `commands/carapace.md`).

## Gleiphnir (`gle`) — host / VM orchestration (wraps `mise`)

Spec: `vm/files/carapace/specs/gleiphnir.yaml:1` (`run:` on every leaf → `carapace --run` / `~/.config/carapace/bin/gleiphnir` shim). Legacy wrappers `vm/files/gleiphnir:1` (bash) + `vm/files/gleiphnir.ps1:1` (pwsh) remain for fallback but are no longer required; `container/files/gleiphnir` removed (host-only). Each leaf execs `mise run <colon-task>` (see `mise.toml:10`) via spec `run:`. Cloud-init installs to `/usr/local/bin/gleiphnir` + `/usr/local/bin/gle` (`vm/cloud-init/user-data.yaml.tpl:110`); host uses carapace shim (see `commands/carapace.md`).

| Gleiphnir | → `mise run` | Description |
|---|---|---|
| `gleiphnir deps` | `mise run deps` | Host dependency check |
| `gleiphnir up` | `mise run up` | Full bring-up |
| `gleiphnir down` | `mise run down` | Tear down |
| `gleiphnir smoke` | `mise run smoke` | Smoke test |


## Carapace Setup

Full setup (in-container automatic + host manual) is now documented at:

→ [`commands/carapace.md`](commands/carapace.md)

Summary:

```bash
# In-container (automatic via dotfiles)
echo $CARAPACE_SPEC_DIR  # /etc/carapace/specs
carapace --list | grep -E "fenrir|gleiphnir|mise"

# On host (manual)
mise use carapace@latest
mkdir -p ~/.config/carapace/specs
ln -sfn "$PWD/container/files/carapace/specs/fenrir.yaml" ~/.config/carapace/specs/fenrir.yaml
ln -sfn "$PWD/vm/files/carapace/specs/gleiphnir.yaml" ~/.config/carapace/specs/gleiphnir.yaml
ln -sfn "$PWD/container/files/carapace/specs/mise.yaml" ~/.config/carapace/specs/mise.yaml
echo 'source <(carapace _carapace)' >> ~/.bashrc
export PATH="$HOME/.config/carapace/bin:$PATH"  # for runnable gleiphnir shim
gleiphnir --help
```

`gleiphnir` is a thin alias over `mise run` (`gle vm start` ≡ `mise run vm:start`), carapace-completeable via shim.

## Examples

```bash
# In-container (ssh as sandbox user)
fen tools list
fen tools volumes              # gdu TUI
fen browse                     # yazi at $PWD
fen browse /opt/mise-shared    # yazi
fen sbom all --format cyclonedx --output /work/sbom
fen journal --last 20 --failed
fen firewall list
fen user list

# On host (repo root)
gle deps
gle image download && gle vm prepare && gle vm start && gle vm:ssh:wait  # or gle up
gle user add USER=bob KEY=~/.ssh/id_ed25519.pub
gle fw allow 192.168.1.10 && gle fw enforce
gle container build && gle sbom all
gle obs start && gle obs open
gle secrets sync && gle smoke
gle down
```

See `docs/fenrir-gleiphnir-plan.md` (archived) and `docs/architecture.md` for internals. Detailed per-command docs are in `docs/commands/` (see above).
